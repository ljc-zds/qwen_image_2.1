# Reference adaptation

Source: https://imageprompt.org/image-to-prompt
Inspected in Chromium on 2026-10-06 at desktop and mobile widths. Detailed computed styles are in imageprompt.json and layout-details.json; screenshots are in docs/design-references/.

The reference uses white, #7f00ff, #f8fafc and #e2e8f0; DM Sans; a 48px bold centered heading; tool tabs; a gray two-column form/showcase area; small-radius controls; white floating browser-style example cards; centered section headings; bordered FAQ cards and a pale-purple closing section.

This is a visual adaptation of Prism Studio. It retains its Qwen Image 2.1 SEO, existing image generation/edit/transparent modes, prompt reuse, file validation, localization and honest service status. Original ad content, testimonials, brand and claims are not copied.

Interactions remain click/keyboard-driven: mode tabs, upload/drop, prompt examples, aspect ratio, mobile menu and FAQ. Header is sticky, button/card hovers transition in 200ms. The original carousel appearance is adapted as a static decorative preview stack; no fake output is introduced.

The original reference showcase images have been replaced by original Prism Studio imagegen artwork. Only the visual stack/transition behavior is retained.
